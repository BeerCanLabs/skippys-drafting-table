Recorded characteristics

Quoted from the deployment pattern.

Verification
Verified read-only on 2026-11-15 and re-verified on 2026-11-18 against AWS account 566332862296, us-east-1.
Deployment targets
AWS us-east-1, ECS cluster factory-prod on Fargate/Fargate Spot (01M7GWTG2S-X9V8), plus operator-workstation for the Factory CLI & Benchmark Harness (01M7KQAQCD-01CD).
Availability requirement
Each Factory kernel and console service runs desired 1 / running 1. Agent compute is zero when idle. gatekeeper-egress uses FARGATE_SPOT. Availability target not yet set.
Data classification
Confidential (agent-factory .draft/sdp.yaml says the ledger holds metadata plus hashes and the mind holds adopter data).
Failure domain
Single region, single cluster. Losing the control plane blocks wakes and MCP. Losing one agent task does not take down the factory.
External dependencies
Cloudflare edge proxy (01M7GTBMQS-YRGF) and Cloudflare Access (01M7GWTG2T-VA2G); ALB factory-prod (01M7GWTG2T-M2Q0); Cloud Map factory.internal (01M7GWTG2T-8A54); Secrets Manager (01M7GWTG2T-3PQY); S3 mind bucket (01M7GWTG2T-GYW1); S3 WORM ledger bucket (01M7GWTG2T-F1WG); S3 config bucket (01M7QCKQX8-9J6P); S3 skill packages bucket (01M7QCKQX8-V947); EFS ledger (01M7GWTG2T-KR1Y); ECR (01M7GWTG2T-0NKZ); CodeBuild admission/skill builders (01M7KQAQCD-WD0R); EventBridge factory event bus (01M7KQAQCD-GHF4); CloudWatch (01M7GWTG2T-TQEB); KMS AWS-managed keys (01M7GWTG2T-JHTR).
Inter service connections
The ALB routes the default host to the control plane and factory-dashboard to the console. Kernel services find each other through Cloud Map factory.internal. Co-tenanted client/product workloads (Agent Garrison 01M7QCKQX8-V20K, Closing Climb 01M1N137Q4-BNT8) are registered separately.
Secrets management
AWS Secrets Manager referenced as ECS container secrets (control-plane 6, gatekeeper-ingress 2, gatekeeper-egress 2, console 0) and queried via AWS SDK by packages/secrets-bind. The gatekeepers inject credentials so agent tasks hold only their run token, except the registered gap GAP-031 (see decision record 01M7GYV3B6-YE24).
Iac automation
Terraform in BeerCanLabs/agent-factory landing-zones/aws with an S3 backend.
Observability
CloudWatch Logs /ecs/factory-prod (30 days), Container Insights, ADOT collector sidecar on control-plane and gatekeeper-egress. No factory alarms or dashboards found.
Pattern deviations
Live ECS, the control plane, gatekeeper-ingress and gatekeeper-egress are always-on services; agents scale to zero (see decision record 01M7GYV3B6-K9CZ).
Product registration
Registered in drafting-table as BeerCanLabs Agent Factory (01M1N137Q5-AFAC).
Incomplete
Requirements are answered by the AWS decision records listed above. Known gaps are recorded as not-compliant requirementImplementations. Still open: synthetic test data, local DRAFT validation of the repo SDP, session/JWT hardening (MFA, rate limiting), and reference-architecture conformance: the agent-factory repo SDP maps the orchestrated-tasks pattern to RA 01KV0REFAR-CMSV, but declaring it needs the community RA vendored/adopted and its ingress, orchestration, mesh, data-store and logs slots bound first. Autoscaling policies and standalone security group objects are not yet modeled.
